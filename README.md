# Memory Match Game

A card-matching game for practicing memory skills.

## Features

- Randomized cards
- Matching pairs
- Move tracking

## How to Use

Select two cards to find matching symbols.

## Technologies

- HTML
- CSS
- JavaScript

## Running Locally

Open `index.html` in a modern web browser.
## Manual Testing Checklist

- [ ] Start a game and flip two different cards.
- [ ] Match a pair and verify that it remains revealed.
- [ ] Restart during a mismatch and check that the new board works.
